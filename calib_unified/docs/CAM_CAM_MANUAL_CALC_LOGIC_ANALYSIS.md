# 相机-相机外参手动调整 — 计算逻辑分析

## 1. 结论摘要

- **对极几何公式与 OpenCV 约定**：正确，与标定结果存储约定一致。
- **未发现严重逻辑错误**，能正确反映当前外参下的对极约束。
- **存在若干潜在问题**：畸变未考虑、极线退化时数值不稳定、平移尺度与 E 尺度歧义需在文档/交互上说明。建议按优先级做小幅加固（见文末）。

---

## 2. 外参与对极几何约定

### 2.1 外参存储（与 cam_cam_calib 一致）

- `ExtrinsicSE3`：`ref_sensor_id = cam0`，`target_sensor_id = cam1`。
- `SO3_TargetInRef`、`POS_TargetInRef` 来自 OpenCV `stereoCalibrate` 的 R、T：
  - OpenCV 定义：R、T 为从**第一台相机到第二台相机**的旋转与平移。
  - 即 **p_cam1 = R * p_cam0 + t**（点从 cam0 变换到 cam1）。
- 因此代码中使用的 `R = extrin.SO3_TargetInRef.matrix()`、`t = extrin.POS_TargetInRef` 与标定输出一致，无需取反或转置。

### 2.2 本质矩阵 E 与基础矩阵 F

- 对极约束（归一化坐标）：**x1^T E x0 = 0**，其中 x0 在 cam0、x1 在 cam1。
- 标准形式：**E = [t]_x * R**（R、t 为 cam0→cam1），满足  
  **x1 · (t × (R*x0)) = 0**，与 `manual_calib.cpp` 中 `CamCamEpipolarCost` 的 `t × (R*p0) · p1 = 0` 一致。

当前实现：

```cpp
Eigen::Matrix3d t_skew;  // [t]_x
t_skew << 0, -t.z(), t.y(), t.z(), 0, -t.x(), -t.y(), t.x(), 0;
Eigen::Matrix3d E = t_skew * R;
Eigen::Matrix3d F = K1.transpose().inverse() * E * K0.inverse();
```

- 像素坐标下 **x1_pixel^T F x0_pixel = 0** 要求  
  **F = K1^{-T} E K0^{-1}**，与上式一致。
- **结论**：E、F 的推导与实现正确。

### 2.3 OpenCV computeCorrespondEpilines

- `computeCorrespondEpilines(points, whichImage, F, lines)`：
  - **whichImage=1**：points 在第一幅图（img0），输出为第二幅图（img1）上的极线。
  - **whichImage=2**：points 在第二幅图（img1），输出为第一幅图（img0）上的极线。
- 当前用法：img0 网格点 + whichImage=1 → 在 img1 上画极线；img1 网格点 + whichImage=2 → 在 img0 上画极线。与 OpenCV 约定一致。
- **结论**：F 与 whichImage 使用正确。

## 3. 极线绘制与数值稳定性

### 3.1 直线方程与端点

- 极线 **l = (a, b, c)**，方程 **a*x + b*y + c = 0**。
- 当前用两端点画线：
  - 默认：`p1 = (0, -c/b)`，`p2 = (cols, -(a*cols+c)/b)`（假设 b≠0）；
  - 当 **|b| < 1e-6**：按竖线处理，`p1 = (-c/a, 0)`，`p2 = (-c/a, rows)`。

### 3.2 潜在问题：退化极线

- 当 **|b| < 1e-6** 且 **|a| 也很小**（接近 0）时，**-c/a** 会非常大或产生 NaN，导致无效线段或绘制异常。
- 出现场景：极线接近“在无穷远”或 F 接近奇异（例如 t 很小时 E 接近零矩阵）。
- **建议**：在 `|b| < 1e-6f` 的分支内增加 **if (std::abs(a) < 1e-6f) continue;**，跳过该退化极线的绘制。

### 3.3 F 矩阵类型

- `cv::eigen2cv(F, F_cv)` 得到 64F；`computeCorrespondEpilines` 接受 `InputArray`，64F 有效，无类型错误。

## 4. 畸变未参与对极线

### 4.1 现状

- 对极线是在**无畸变针孔模型**下由 K0、K1 和当前外参算出的。
- `manual_cache_` 中的 `cam0_image`、`cam1_image` 来自精标定时的**原始帧**，一般为**带畸变**的像素坐标。
- 因此：**当前是在“畸变像素”上画“无畸变模型”的极线**。存在畸变时，极线不会严格经过真实对应点，视觉效果上会有偏差。

### 4.2 影响与建议

- **影响**：畸变越大，极线“穿过对应点”的观感越差；不影响 6-DOF 的数学正确性，只影响可视化与主观判断。
- **建议**（可选，按需实现）：
  - 方案 A：对手动阶段使用的图像先做 **undistort**（用 `intrin0/intrin1` 的 dist_coeffs），再用同一 K 做对极线绘制；
  - 方案 B：在文档中说明“对极线为无畸变模型下的参考，若相机畸变较大可先做去畸变再标定”。

---

## 5. 平移尺度与 6-DOF 调整

### 5.1 对极约束与平移尺度

- 从本质矩阵 E 只能得到 **t 的方向**，**不能恢复尺度**（双目尺度通常由三角化或已知基线给出）。
- `stereoCalibrate` 返回的 T 一般带物理尺度（如米），当前手动调整的 `trans_step_m` 也是按米设计的，与“有尺度”的标定结果一致。

### 5.2 手动调平移

- 用户可任意调整 Tx/Ty/Tz。若初值来自仅用对极约束的求解（单位 t），则手动改平移会改变基线尺度；若初值来自 stereoCalibrate，则是在已有尺度上微调。
- **结论**：无计算错误；若希望避免误解，可在 UI 或文档中注明“平移尺度依赖标定初值（如立体标定给出的是有尺度结果）”。

---

## 6. t 接近零时的退化

- 当 **t ≈ 0**（两光心几乎重合）时，**[t]_x 接近零矩阵**，E 和 F 接近奇异，极线方向不稳定，绘制可能异常。
- 这是几何退化情形，不是实现 bug。可选：若 **||t|| < 阈值**，在界面提示“基线过小，对极线可能不可靠”或暂时不画极线。

---

## 7. 与 Ceres 对极代价的一致性

- `CamCamEpipolarCost` 使用 **t × (R*p0) · p1 = 0**，与 **E = [t]_x * R** 及 **x1^T E x0 = 0** 一致。
- 手动调整使用的 R、t 与点击精化优化的是同一套外参表示，无约定不一致问题。

---

## 8. 建议修改优先级

| 优先级 | 问题 | 建议 |
|--------|------|------|
| 高 | 极线退化时 a、b 均很小时 -c/a 可能爆炸或 NaN | 在 b 分支内若 \|a\| < 1e-6f 则 **continue** 跳过该线 |
| 中 | 畸变导致极线视觉偏差 | 文档说明；或对手动阶段图像先 undistort 再画极线 |
| 低 | t 很小时 F 奇异 | 可选：检测 \|\|t\|\| 过小并提示或跳过绘制 |
| 低 | 平移尺度来源 | 在 MANUAL_EXTRINSIC_ADJUSTMENT 或工具提示中简要说明 |

---

## 9. 总结

- **核心计算（R/t 约定、E/F 公式、whichImage、像素极线）均正确**，与 OpenCV 及现有 cam_cam 标定、Ceres 对极代价一致。
- **未发现严重错误**；主要风险来自**畸变未参与可视化**和**极线退化时的数值稳定性**。建议至少做“退化极线跳过”的小改动，其余按需做文档或预处理即可。
