# lidar_rear：标定结果 vs lidar_vert 参考 差异说明

## 1. 矩阵对比（4×4 行优先）

| 来源 | 旋转 R (3×3) | 平移 t (m) |
|------|--------------|------------|
| **lidar_vert.yaml**<br/>T_Body_Lidar | `[-1, 0, 0]`<br/>`[ 0, 0, 1]`<br/>`[ 0, 1, 0]` | **[-0.550, 0.030, 0.050]** |
| **标定结果**<br/>T_Imu_Lidar | `[ 1, ~0, ~0]`<br/>`[~0, -1, ~0]`<br/>`[~0, ~0, -1]`<br/>（小量 ~0.0003 忽略） | **≈ [0, 0, 0]** |

约定：两者均为「把 LiDAR 系下的点变到 Body/IMU 系」：`p_body = T * p_lidar`。若 Body=IMU，理论上应一致。

---

## 2. 旋转差异

- **标定 R** ≈ 绕 X 轴 180°：`Rx(π)` → 对角 (1, -1, -1)，即 **X 不变，Y/Z 反向**。
- **参考 R** = `[-1,0,0; 0,0,1; 0,1,0]` = **绕 X 轴 180° + Y 与 Z 轴互换**（Body Y = Lidar Z，Body Z = Lidar Y）。

因此：
- **共同点**：绕 X 的 180° 已对齐（prefer_180 后标定选对了 180° 侧）。
- **差异**：参考多了一个 **Y↔Z 轴互换**；标定结果没有这部分，所以和参考仍差一个「Y/Z 互换」的旋转。

可能原因：
1. **LiDAR 坐标系定义不同**：例如 Ouster 与 Body 的轴向约定不同（谁为“上”、谁为“前”），会体现为 Y/Z 互换或 90° 旋转。
2. **手眼仅由旋转对估计**：若运动以水平旋转为主，绕 X 的 180° 可观测，但「Y/Z 互换」对应的那部分旋转可能激励不足或不可区分，解会落在 Rx(π) 而非 Rx(π)*Swap(Y,Z)。

---

## 3. 平移差异

- **标定**：t ≈ **0**（数量级 1e-6 ~ 1e-5 m）。
- **参考**：t = **[-0.550, 0.030, 0.050]** m（约 55 cm 沿 Body -X）。

原因简述：
- 手眼方程只约束**旋转**，不约束平移。
- 平移是后续用**速度/里程计**约束估计的；若运动近似平面、或沿某方向激励不足，平移会退化，常得到接近 0 的解（日志里也有 `trans_rms_m_s` 极小、平移约束弱的情况）。

---

## 4. 小结与建议

| 项目 | 标定 vs 参考 | 建议 |
|------|-------------|------|
| **绕 X 的 180°** | 已一致 | 保持当前 handeye 策略即可。 |
| **Y/Z 互换** | 标定缺少 | 若参考是真实安装：可 (1) 检查 LiDAR 与 Body 的坐标系定义是否一致；(2) 用参考外参做**旋转初值/先验**再精化；或 (3) 标定后**后处理**乘上 Y↔Z 互换矩阵（若确认是约定差）。 |
| **平移** | 标定≈0，参考≈[-0.55,0.03,0.05] | (1) 用 lidar_vert 的平移作**平移初值**或固定平移先验；(2) 或标定后**直接采用参考平移**，仅用标定旋转。 |
