# 标定板数据采集需求（离线标定用）

> 适用于 UniCalib 离线多传感器外参标定（相机 + LiDAR 为主）

## 1. 标定板规格（必须一致）

| 参数          | 推荐值     | 说明                     |
|---------------|------------|--------------------------|
| 类型          | 棋盘格     | Chessboard               |
| 内角点        | 9 列 × 6 行 | `board_cols=9, board_rows=6` |
| 方格尺寸      | 25 mm      | `square_size=0.025`      |
| 材质          | 高对比度、平整、无反光 | 推荐亚克力或专业标定板   |

**注意**：实际制作/采购时必须与 `unicalib_example.yaml` 中的 `lidar_camera` / `cam_cam` 配置完全一致。

## 2. 采集环境与设备要求

- **光照**：均匀、无强直射，避免反光和阴影
- **背景**：干净，减少干扰平面
- **静止**：标定板必须完全静止（ tripod 或固定支架）
- **同步**：推荐硬件触发或 PTP/时间同步；否则需软件时间戳对齐（误差 < 10 ms）
- **覆盖**：标定板需同时出现在相机和 LiDAR 视野中

## 3. 采集场景与姿态要求（核心）

每组数据至少采集 **20~40 帧**（推荐 30+），必须满足以下分布：

### 3.1 距离分布
- 近距离（0.8~1.5 m）：占 30%
- 中距离（1.5~3 m）：占 50%
- 远距离（3~5 m）：占 20%

### 3.2 角度与位置分布（必须多样化）
- **正对**（board 平行于相机平面）
- **俯仰 ±15°~30°**
- **偏航 ±15°~40°**
- **侧倾 ±10°~20°**
- **四角 + 中心**：标定板分别位于图像/LiDAR 视场四角和中心
- **边缘覆盖**：至少 5 帧让标定板贴近图像边缘（测试畸变补偿）

### 3.3 每帧质量 checklist
- [ ] 相机图像清晰，无运动模糊
- [ ] 棋盘格角点完整可见（至少 80% 以上）
- [ ] LiDAR 点云中标定板平面明显（≥ 200 个点）
- [ ] 标定板无遮挡、无运动
- [ ] 时间戳对齐（文件名或 CSV 记录）

## 4. 数据存储结构（推荐）

```
calib_data_YYYYMMDD/
├── camera/
│   ├── images/
│   │   ├── 000001.jpg
│   │   ├── 000002.jpg
│   │   └── ...
│   └── timestamps.csv          # frame_id, timestamp_ns, sensor_id
├── lidar/
│   ├── pcd/
│   │   ├── 000001.pcd
│   │   └── ...
│   └── timestamps.csv
├── radar/                      # 可选（若做 radar-camera）
│   └── *.csv
├── imu/                        # 可选
│   └── *.bag / *.csv
└── calib_board.yaml            # 记录板参数（便于复用）
```

`timestamps.csv` 示例：
```csv
frame_id,timestamp_ns,sensor_id
000001,1716883200123456789,camera_center_front
000001,1716883200123456790,lidar_main
```

## 5. 采集脚本建议（伪代码）

```python
# 伪代码示例
for pose in poses:
    wait_for_stable()           # 等待标定板静止
    trigger_all_sensors()       # 硬件触发或软件同时采集
    save_image(camera_frame)
    save_pcd(lidar_frame)
    record_timestamp()
```

## 6. 注意事项与禁忌

- **禁忌**：单距离、单角度、标定板只在中心、运动模糊、反光严重
- **推荐**：先采集 10 帧快速验证 pipeline，再补全多样性数据
- **验证**：采集后立即用可视化工具检查角点检测和点云平面是否正常
- **备份**：原始数据 + 处理后数据分开存储

---

**目标**：用这套采集规范获得高质量、多样化的标定数据，可直接喂给 `lidar_camera` / `cam_cam` 模块进行稳健离线标定。

如需针对特定传感器（radar、IMU）或 rosbag 格式扩展，请补充说明。
